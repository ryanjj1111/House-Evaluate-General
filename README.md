# 🏠 房屋試算｜房貸・出租・出售

網址：https://ryanjj1111.github.io/House-Evaluate-General/

把一間房子從「買進 → 自住 → 出租 → 出售」的每個決定，換算成每月現金流和每年淨資產，並讓多個情境並排比較。純 HTML／JavaScript，不需要建置，資料只存在自己的瀏覽器。

## 目前完成

- 💰 **房貸**：單一利率（預設）、自訂多段利率、新青安補貼逐年遞減、寬限期、本息／本金均攤、提前還款（縮短年限／降低月付／每月多還）、升息壓力測試、逐年／逐月還款明細
- 🔑 **出租 vs 自住**：四種出租方式（一般、公益出租人、社宅包租、社宅代管）的租賃所得稅、房屋稅、地價稅，新青安違規或轉貸後的新利率（上方圖表用虛線比較）、🔁 轉貸試算（費用、新年限、寬限期、回本月數），搬出後自己的居住成本，打平月租
- 🏘️ **租金行情**：GitHub Actions 每月整理實價登錄租賃資料（各縣市、行政區、房數的月租中位數與每坪月租），一鍵帶入出租月租與自己租屋的房租
- 📈 **圖表**：餘額與利率、每月月付（本金＋利息堆疊）、每年本息；範圍 5／10／全部／自訂年數；點圖例開關線；⚙️ 選擇顯示的線與重點卡；📌 固定
- 每個區塊都可以收合（會記住）
- 📖 **使用說明**：操作方式、公式與規則、名詞
- 💾 **資料**：只存在瀏覽器，匯出／匯入 JSON、↺ 重置
- 📱 **可以安裝到手機主畫面**（PWA），離線時用上次開啟的版本

舊版出租／賣房評估暫時保留在 [legacy.html](legacy.html)，新版完成對應功能後移除。

## 檔案

| 檔案 | 內容 |
|---|---|
| `js/policy.js` | 政策與稅率參數（附來源與確認日） |
| `js/state.js` | 資料格式：預設值、舊設定檔轉換（純函式） |
| `js/fields.js` | 欄位定義表：名稱、單位、範圍、ⓘ 說明 |
| `js/engine.js` | 計算核心（純函式，不碰畫面；還款表有快取） |
| `js/charts.js` | canvas 圖表（線、階梯、面積堆疊、長條） |
| `js/ui-core.js` | 儲存、欄位、收合、分頁、使用說明 |
| `js/ui-loan.js`、`js/ui-rent.js`、`js/ui-chart.js` | 💰 房貸＋📅 明細、🔑 出租、主圖表 |
| `js/ui-market.js` | 🏘️ 租金行情（讀 `data/rent/`） |
| `js/main.js` | 啟動與整體流程 |
| `tools/fetch_rent.py` | 下載並整理實價登錄租賃資料（Actions：更新租金行情，每月 6 日） |
| `tools/test/rent_data_test.py` | 租金整理的測試（虛構 CSV） |
| `js/tip.js` | ⓘ 說明小視窗（沿用投資帳本） |
| `tools/test/engine-test.mjs` | 測試：`node tools/test/engine-test.mjs` |
| `tools/bump.mjs` | 改版時更新 js 版本號：`node tools/bump.mjs` |

本工具僅供試算，非貸款、稅務或投資建議；實際以銀行與主管機關為準。
