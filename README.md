# 🏠 房屋試算｜房貸・出租・出售

網址：https://ryanjj1111.github.io/House-Evaluate-General/

把一間房子從「買進 → 自住 → 出租 → 出售」的每個決定，換算成每月現金流和每年淨資產，並讓多個情境並排比較。純 HTML／JavaScript，不需要建置，資料只存在自己的瀏覽器。

## 目前完成

- 💰 **房貸**：多段利率、新青安補貼逐年遞減、寬限期、本息／本金均攤、提前還款（縮短年限／降低月付／每月多還）、升息壓力測試、逐年／逐月還款明細
- 📐 **公式**：每個數字怎麼算出來的
- ⚙️ **資料**：示範資料（虛構）／我的資料（只存在瀏覽器），匯出／匯入 JSON
- 📱 **可以安裝到手機主畫面**（PWA），離線時用上次開啟的版本

## 規劃中

1. 🔑 出租：四種租賃所得申報方式、房屋稅／地價稅、新青安違規代價、搬出後自己的居住成本、實價登錄租金行情
2. 💸 出售：依日期判斷房地合一稅級距、自住優惠（400 萬／10%）、售出瀑布圖、最佳出售月
3. 📊 情境比較：事件時間軸、多情境淨資產曲線、自動結論、稅率時間帶
4. 展示模式、分享連結
5. 🏘️ 實價登錄：區域與社區行情比較

舊版出租／賣房評估暫時保留在 [legacy.html](legacy.html)，新版完成對應功能後移除。

## 檔案

| 檔案 | 內容 |
|---|---|
| `js/policy.js` | 政策與稅率參數（附來源與確認日） |
| `js/engine.js` | 計算核心（純函式，不碰畫面） |
| `js/charts.js` | canvas 圖表 |
| `js/ui.js`、`js/main.js` | 畫面與儲存 |
| `js/tip.js` | ⓘ 說明小視窗（沿用投資帳本） |
| `tools/test/engine-test.mjs` | 計算測試：`node tools/test/engine-test.mjs` |

本工具僅供試算，非貸款、稅務或投資建議；實際以銀行與主管機關為準。
